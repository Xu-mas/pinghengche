# 基于STM32F103的平衡小车控制

## 1. 功能需求

1. **二轮平衡车，实现自主站立**
   → 实现闭环控制，动态平衡能力，静止时姿态保持在 ±2° 内，响应时间 ≤ 50ms。

2. **二轮平衡车能够实现前进、后退、原地转向**
   → 前进/后退：通过电机正反转控制；原地转向：差速控制（一边前进，一边后退）。

3. **实现三种不同的前进后退速度：低、中、高**
   → 速度档位通过蓝牙指令切换，分别对应 PWM 占空比 30%、60%、90%；支持实时切换。

4. **蓝牙下发所有控制指令**
   → 指令格式统一：`CMD,vel=speed,dir=type`，支持动态下发速度、方向、模式；波特率 115200，丢包率 < 0.1%。

5. **屏幕显示当前前进速度、当前俯仰角度、电池电量**
   → 显示频率 ≥ 1Hz；角度精度 ±0.5°，速度显示带百分比，电量显示为 0~100%（基于 ADC 分压电压计算）。

6. **具体性能指标（补充明确）**
   - 平衡保持时间：≥ 30min（持续单点站立）
   - 响应延迟：从姿态扰动到电机响应 ≤ 80ms
   - 速度调节精度：±5%
   - 电池续航：≥ 45min（12V 2000mAh LiPo）

---

## 2. 具体设计要求

1. **平衡车力学原理**
   → 采用倒立摆模型，系统稳定条件：控制输入与俯仰角误差成正比。

2. **电机选型**
   → 选用带编码器的直流电机，编码器分辨率 ≥ 500 PPR，连续运行电流 ≤ 1A。

3. **主控**
   → STM32F103C8T6，需支持 PWM 输出（TIM3）、定时器输入捕获（TIM2）、I2C、UART。

4. **供电系统**
   → 采用 12V 锂电池供电，需包含电压分压采样电路（100k+10k），支持 3.3V 单电源供电。

5. **电机驱动模块**
   → 必须支持双电机独立控制，驱动电路隔离良好，最大输出电流 ≥ 1.2A。

6. **闭环控制理论**
   → 采用 PID 控制，控制周期固定为 10ms，积分项需防饱和。

7. **PID的控制**
   → 初始化参数：Kp=80，Ki=0.05，Kd=10，支持通过串口动态调整。

8. **MPU6050采集**
   → 采样频率 100Hz，数据传输稳定，无中断丢失；建议使用 I2C 通信。

9. **编码器测速**
   → 采用 STM32 定时器编码器模式，测量转速，支持 500 PPR 以上分辨率。

10. **OLED 显示**
    → 使用 128×64 SSD1306 模块，支持中文显示，通信接口 I2C，刷新率 ≥ 1Hz。

11. **蓝牙透传**
    → 模块为 HC-05 或 HC-06，配置为透传模式，波特率 115200，指令解析准确率 ≥ 99.9%。
